# Как читать временную диаграмму

Сначала выполните одиночное сравнение, а не параметрическую серию. Серии сохраняют статистику без подробной трассы. В расширенных настройках нужен ненулевой лимит событий.

В разделе «Диаграмма передач» есть два представления.

**Разбор пакета** показывает конкретный пакет между передатчиком и приёмником. Стрелка вправо: данные, влево: ACK/NACK. Возле концов указаны реальные моменты событий. Схема этапов не нарисована в масштабе времени: короткая TX иначе была бы неразличима рядом с большим RTT.

**Общая диаграмма** показывает параллельную работу процессов. Время идёт слева направо. P0, P1, …: номера HARQ-процессов, а не номера пакетов. Один процесс обслуживает много пакетов. Полоса: TX, кружок: RX, ромб: полученная обратная связь. Пустые интервалы обычно означают ожидание ACK/NACK; передатчик может использовать другие процессы.

Пример для модели: RTT=500 мс, передача=1 мс, начало t=0.

1. t=0…1 мс: блок передаётся.
2. t=251 мс: приёмник получает полный блок и декодирует его.
3. При успехе формируется ACK, при ошибке: NACK.
4. t=501 мс: подтверждение приходит передатчику.
5. После ACK процесс можно использовать для следующего пакета. После NACK отправляется повтор, если не исчерпаны попытки и дедлайн.

**Пакет уже доставлен в t=251 мс, но процесс занят до t=501 мс.** Это разные метрики. В конфигурации RTT исключает время TX, поэтому первый цикл занимает 501 мс.

При упреждающем burst Adaptive несколько копий отправляются до получения обратной связи; дополнительные RX могут быть дубликатами. Подтверждение формируется по последнему блоку burst, поэтому между успешным RX первой копии и освобождением процесса есть дополнительная задержка.

При потерянной обратной связи ждут таймаут. Таймаут: событие локального таймера передатчика, не сообщение от приёмника. Даже успешно доставленный пакет может передаваться повторно, если его ACK потерялся.

Если события закончились посередине пакета, возможны два ограничения: горизонт моделирования и лимит сохранённых событий. Отсутствующее событие в таком случае не следует трактовать как потерю пакета. Увеличьте лимит трассы или время моделирования и повторите одиночный прогон.

Кнопка «Показать его временной интервал» меняет окно общей диаграммы на диапазон событий выбранного пакета. Уменьшение окна позволяет различить короткие TX.
