МАТЕМАТИЧЕСКАЯ МОДЕЛЬ

Условия корректного сравнения

Один радиоканал, независимые процессы

Источник насыщенный: новый пакет появляется при первой TX. В каждый момент передаётся один блок. Процессы независимо ожидают обратную связь. Очередь источника и задержки приложений не моделируются.

Время и радиоресурсы

RTT = распространение туда и обратно плюс обработка, без времени TX. Приём: t + T_TX + RTT/2; ACK: t + T_TX + RTT. Идеальный предел загрузки: min(1, N·T_TX / (RTT + T_TX)).

Первая передача: n = B/R символов. CC повторяет n символов, IR добавляет f·n. Скорость символов и энергия на символ одинаковы. Длительность IR-повтора — f·slot_ms.

Приближённое декодирование

BLER(γ) = 1 / (1 + exp(k·(γ_dB − γ₀))). CC: γ_eff = Σγᵢ. IR: I = Σnᵢ·log₂(1 + γᵢ), γ_eff = 2^(I/n) − 1. В идеальном режиме используется порог ёмкости: log₂(1 + γ_eff) ≥ R.

Реальные модуляция, CRC, LDPC, LLR и Doppler в сетевом симуляторе не рассчитываются. Это абстрактная исследовательская модель, а не реализация 3GPP NR.

ИССЛЕДОВАТЕЛЬСКИЙ ПРОТОКОЛ

От гипотезы к проверке

Adaptive Delay-Aware HARQ

На старте пакета выбираются CC/IR, число процессов, лимит попыток и упреждающий burst. Оценка полезности включает нормированные goodput, задержку, превышение целевых потерь и память. CSI обновляется только по полученной обратной связи; средняя SNR конфигурации — начальное априорное значение.

Весовые коэффициенты: 1; 0,15; 2; 0,02. Модель предсказания упрощена и не учитывает корреляцию замираний. Алгоритм не гарантирует улучшения и требует проверки для каждого режима.

Статистика и границы наблюдения

95% ДИ строится по средним независимых seed с распределением Стьюдента. При одном seed ДИ не определён. Для adaptive − parallel также вычисляется парный ДИ разницы goodput.

Успех — уникальный приём до горизонта; потеря — исчерпание попыток или дедлайн. Остальные пакеты — censored. Потери среди разрешённых пакетов могут быть смещены коротким горизонтом. Рекомендуется увеличить длительность и проверить сходимость.

Модели канала и буфера

AWGN, независимый Rayleigh, коррелированный Rayleigh AR(1), lognormal shadowing. Канал индексируется временем по общей сетке для всех алгоритмов. Буфер резервируется на весь пакет; IR — под максимальную избыточность. Отсутствует ограничение числа RV реального NR.

Теоретическая база

3GPP TR 38.821 V16.0.0, разделы о HARQ в NTN. 3GPP TS 38.300 V18.8.0, архитектура NR/NTN. Ссылки и полный протокол — в docs/METHODOLOGY.md и экспортированном отчёте.
